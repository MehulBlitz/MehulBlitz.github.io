Why the numbers above are current — not screenshots

  1. Each repo ships a GitHub Actions workflow (setup-python → pip install → full retrain with GridSearchCV → commit refreshed artifacts/metrics.json + figures).
  2. Workflows run on a schedule (churn monthly, fraud quarterly, house monthly) and on every push that touches training code.
  3. This page fetches each repo's metrics.json live at page load and re-renders the cards — the same numbers the repos' READMEs show.
  4. Interactive demos: each repo includes a Gradio app (python app.py); the churn and fraud apps ship with trained models included.
